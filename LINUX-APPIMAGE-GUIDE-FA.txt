راهنمای ساخت نسخهٔ لینوکس برنامهٔ حامی

این پروژه برای ساخت نسخهٔ دسکتاپ از Electron استفاده می‌کند و خروجی موردنظر AppImage است.

ساخت محلی (در سیستمی که Node.js و اینترنت دارد):
  npm install
  npm run desktop:linux

خروجی در پوشهٔ release قرار می‌گیرد.

ساخت با GitHub Actions:
1. فایل‌های این پروژه را در مخزن GitHub قرار دهید.
2. مطمئن شوید فایل .github/workflows/build-appimage.yml نیز در مخزن ایجاد شده است.
3. به زبانهٔ Actions بروید و گردش‌کار Build Hami Tools AppImage را انتخاب کنید.
4. روی Run workflow کلیک کنید.
5. پس از پایان موفق، فایل hami-tools-linux-appimage را از بخش Artifacts همان اجرا دانلود کنید.

نکته‌ها:
- این خروجی از اطلاعات localStorage جدا از مرورگر استفاده می‌کند. قبل از استفادهٔ واقعی، از اطلاعات نسخهٔ فعلی پشتیبان بگیرید و در صورت پشتیبانی برنامه آن را به نسخهٔ دسکتاپ وارد کنید.
- برای جست‌وجوی آنلاین ابزاررضا، اتصال اینترنت لازم است.
- ساخت AppImage در محیط فعلی انجام نشد، چون دسترسی شبکه به npm registry در این محیط با خطای DNS مواجه شد؛ فایل نهایی باید در سیستم محلی دارای اینترنت یا GitHub Actions ساخته شود.
